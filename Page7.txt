Destructor(Only in C++)
A destructor is a special function that is called automatically when an object is destroyed or goes out of scope.
It is used to free memory and other resources.
The destructor name is the same as the class name but starts with ~.
It has no return type.
It has no parameters.
A class has only one destructor.

Java does not have destructors instead it has a Garbage Collector.

Garbage Collector.
It is a memory management feature.

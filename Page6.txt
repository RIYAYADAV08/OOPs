Constructor
A constructor is a special method that is called automatically only once when an object is created.
It is used to initialize the object.
The constructor name is the same as the class name.
It has no return type(not even void)
Memory is allocated first, then the constructor is called to initialize the object.


There are three types:
1.Non-Parameterized(Default) Constructor
It has no parameters.
It is used when we do not want to pass any values while creating an object.


2.Parameterized Constructor
It accepts one or more parameters.
It is used to initialize object values during object creation.


3.Copy Constructor
It crates a new object by copying the value of another object.
In java, we create the copy constructor ourselves.

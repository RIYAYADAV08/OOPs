# OOPs — Core Subject Preparation for Placements

This repository contains my Object-Oriented Programming (OOPs) notes prepared as part of my **core subject preparation for campus placements and technical interviews**.

The notes cover fundamental OOPs concepts in C++ and Java, with simple explanations, code examples, comparisons, and MCQs for revision.

- Introduction to OOPs and its advantages
- Procedural Programming vs OOPs
- Classes and Objects
- Access Specifiers and Modifiers
- Friend Class in C++
- Four Pillars of OOPs: Encapsulation, Inheritance, Polymorphism, and Abstraction
- Constructors and Their Types
- Destructor in C++
- Scope Resolution Operator in C++
- `this` Pointer / Keyword
- Shallow Copy and Deep Copy
- Inheritance and Modes of Inheritance
- Types of Inheritance
- Diamond Problem
- Compile-Time and Run-Time Polymorphism
- Function Overloading and Function Overriding
- Virtual Functions in C++
- Abstraction and Abstract Classes
- Pure Virtual Functions in C++
- Abstract Classes and Interfaces in Java
- Static Data Members and Functions
- MCQs with Answers and Explanations

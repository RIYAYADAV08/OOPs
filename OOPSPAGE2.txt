Class  
Class is a blueprint or template used for creating objects. It defines properties and behaviour of objects.

Objects
Objects are real-world entities/instances of a class that contains data(object ki info.) and methods(object ky kaam karta hai.).
It is created in memory and used to perform operations.

Data(also called attributes).
Methods(also called behaviours).

Ex- Pen
Class- Pen blueprint
Object- Actual Pen
Attribute- color, tip
Method- settip(), setcolor().
